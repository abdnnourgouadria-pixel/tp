# Library management – TP 2

Beginner-friendly Java library application for Software Engineering TP 2.

## Requirements
- JDK 17 or newer
- IntelliJ IDEA or another Java IDE
- Maven (included in IntelliJ IDEA)

## Run
1. Open this folder in IntelliJ IDEA.
2. Wait for Maven to download dependencies.
3. Open `src/test/java/library/LibraryTest.java` and run the tests.
4. Each Java class is in its own file under `src/main/java/library/`.
